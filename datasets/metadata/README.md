# Combined Plant Disease Dataset Documentation

## Overview
Unified, validated, deduplicated, and class-normalized plant disease image dataset.

## Source Datasets
- **Mendeley Plant Leaf Diseases**: [10.17632/tywbtsjrjv.1](https://doi.org/10.17632/tywbtsjrjv.1)
- **PlantVillage Benchmark**: [10.1038/sdata.2015.65](https://doi.org/10.1038/sdata.2015.65)
